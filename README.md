## 🎯 چرا JS + TS با هم؟

- **JavaScript** زبان وب است: هر مرورگر، هر فریم‌ورک فرانت (React/Next)، و سمت سرور (Node). بدون آن هیچ فرانت‌کاری نیست.
- **TypeScript** = JavaScript + سیستم تایپ. امروز در آگهی‌های شغلی جدی، TS دیگر «امتیاز» نیست — **پیش‌فرض** است.
- ترتیب درست یادگیری: اول JS را واقعی بفهم (نه سطحی)، بعد TS — چون TS فقط «قوانین سخت‌گیرانه‌تر» روی همان JS است.

## 🧪 زمین تمرین

همه‌چیز با Node اجرا می‌شود (فصل ۱ نصبش می‌کنیم):

```bash
mkdir js-ts-playground && cd js-ts-playground
node                # REPL — بنویس و فوری جواب بگیر (exit با .exit)
```

**قانون طلایی دوره:** هر مفهوم را **خودت تایپ و اجرا** کن — JS با خواندن یاد گرفته نمی‌شود، با شکستن و دیدن ارور یاد گرفته می‌شود. خطاها دوست تو هستند.
